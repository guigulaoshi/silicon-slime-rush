# 确定游戏内容

一次整理以下问题，给有合理默认值的问题提供建议；姓名、地点和账号不能代填。

- 地点：城市、街道、学校或园区的准确名称；必经位置、地标、路线数量和长度。
- 名称与语言：中英文标题、简介、故事、需要支持的语言。
- 画面：写实或风格化、配色、当地建筑和植被、天气与时间。
- 车辆：保留现有车或新增车型，车型参考、性能及手感。
- 玩法：竞速、自由驾驶、交通、障碍、道具、难度、单人或分屏。
- 音乐：曲目或风格、音效、资源来源与许可。
- 署名和外链：展示名称、主页、社交账号、二维码、支持入口。
- 交付：目标设备、发布平台、试玩方式、是否收费、资源与服务预算。

问清内容后写简报，列明内容范围、默认选择、验收标准和需要授权的外部操作。不要为了纯实现细节反复打断创作者。
