# 从地点到路线

1. 用地图和官方资料确定每个地点的坐标，核对同名地点。
2. 将地点连成真实可通行道路，明确环线或点到点、起终点、长度、弯道和桥梁。
3. 设置地区边界和投影原点，下载 OSM 与高程快照；缓存可重用，来源必须记录。
4. 构建地图并检查俯视图，再实际驾驶一圈，核对路面坡度、桥梁和障碍净空。
5. 每个重点建筑准备照片、尺寸、朝向、颜色和玩家可见方向的资料卡，再制作模型。
6. 按地区设置立面、屋顶、植被、天空和光照。地标应能从道路视角认出来。
7. 检查每条路线的昼夜、天气、交通、道具、救援与 AI 完赛；保留实际游戏截图。

真实道路与程序生成建筑应明确区分；未经核对不要声称逐栋还原。
