# 交付检查

## 功能与画面

- 每条路线可加载、驾驶、完成和重新开始；起终点、桥面、弯道及恢复点正确。
- 地标符合参考资料，从玩家机位可辨认，建筑、护栏和道具不堵住路线。
- 所有车辆、难度、天气和时段均能使用；AI 能合理完赛。
- 键盘、手柄、触屏、分屏、暂停、旋转屏幕及后台恢复正常。
- 中英文齐全，长文字不溢出；焦点、弹窗、分享、录像、存档和挑战链接可用。
- 首页、菜单卡片、分享卡与新游戏内容一致；作者与社交链接已替换。

## 测试与资源

在游戏目录运行：

```bash
npm run typecheck
npm test
npm run build
npm run e2e
```

在管线目录运行 `.venv/bin/python -m pytest -q`。资源完整性与发布检查按游戏 README 执行。
检查实际浏览器画面及移动设备性能，核对资源许可、署名、加载错误和发布包内容。

## 交付

提供试玩入口、实际游戏截图和录像、测试结论、未验证项目。上架前在真实嵌入环境验证，并确认发布授权。
