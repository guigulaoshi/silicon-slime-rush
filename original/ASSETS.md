# Asset sources

Everything in Silicon Slime Rush was made for the game unless a row below names another source. Each row lists where an asset came from, who made it, its license and what was changed.

| Asset | Source | Author | License | Changes |
|---|---|---|---|---|
| Roads, buildings, land use, water, trees and coastline | [OpenStreetMap](https://www.openstreetmap.org/copyright) | © OpenStreetMap contributors | ODbL | Converted into game geometry by this project's map pipeline |
| Elevation, including distant hills | [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) via AWS Open Data | Multiple data providers | [Terrain attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md) | Sampled into road and terrain heights; no photographed panoramas or invented mountains |
| Billboard lettering font | [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) | Google / Adobe | SIL Open Font License 1.1 | Reduced to the characters the billboards use, with hinting removed |
| Xiaohongshu logo | Wikimedia Commons, File:XiaohongshuLOGO.png <https://upload.wikimedia.org/wikipedia/commons/c/c1/XiaohongshuLOGO.png> | Xiaohongshu | Marked public domain on Wikimedia Commons; the logo is a trademark of its owner | Used unaltered on one billboard, scaled to 160×160 |
| Bilibili logo | Simple Icons 16.30.0 <https://cdn.jsdelivr.net/npm/simple-icons@16.30.0/icons/bilibili.svg> | Bilibili | Icon path data CC0; the logo is a trademark of its owner | Rasterized and shown in Bilibili blue (#00AEEC) on a white rounded tile |
| Social media billboards | The creator's own share cards for seven platforms | guigulaoshi | Owned by the creator; used only in this game | Redrawn as 1024×512 panels with QR codes and simplified platform marks; no profile photos or account names. Platform names and logos are trademarks of their owners |
| All nine vehicles and the travel trailer | Original designs | This project | Owned by this project | Built with Blender scripts: closed bodies, separate wheels and embedded materials; no external textures, manufacturer badges or trademarks |
| Aircraft at Moffett Field | Original models; proportions and paint checked against public NASA, US Air Force, US Navy, US Army, Boeing and Moffett Field Museum material | This project | Owned by this project | Hand-built geometry with original vector markings. The F-22's top camouflage texture was generated with an AI image model from a top-view reference and this model's texture layout. No reference photos, external models, NASA insignia or manufacturer logos are included. The parked aircraft are an imagined display, not the airfield's real collection, and imply no military endorsement |
| Hangar One and the Charleston canopy building | Original Blender models placed on OpenStreetMap footprints | This project | Owned by this project | Shapes observed from public photographs; no photographs are included |
| Buildings, houses, bridges, Alcatraz and Twin Peaks details, billboard structures and ground textures | Original procedural geometry and textures | This project | Owned by this project | Generated by this project's map pipeline from OpenStreetMap shapes; no photographs, satellite imagery or external models. Ground textures take their color and scale from observation only |
| Slime, splashes, weather, water and sky effects | Original shaders and particles | This project | Owned by this project | Generated while the game runs. Glass reflections are baked from the game's own sky, and in the garage from three.js RoomEnvironment (MIT) |
| Music and sound effects | Original compositions and sound design | This project | Owned by this project | The menu theme, three race themes, engines, tires, impacts, slime and interface sounds are all synthesized in the browser; no recordings or borrowed melodies |
| Game icon | Generated with an AI image model from an in-game slime screenshot, in a design direction chosen by the creator | This project | Owned by this project | Transparent PNGs at 64, 180 and 512 pixels for the browser tab, home screen, loading screen and menus |
| Menu backgrounds, track previews, vehicle pictures, link preview and store page images | Captured or rendered from the game itself | This project | Owned by this project | Resized and converted to WebP, PNG or JPEG; the link preview adds the game's title |

## References consulted

These shaped the work above. None of their files, images, recordings or models are included in the game.

- Slime sounds: [Slime Bubble Blowing](https://freesound.org/people/rubberduck9999/sounds/680446/) by rubberduck9999, [Water Splash 2](https://freesound.org/people/qubodup/sounds/210427/) by qubodup and [Cannon explosion](https://freesound.org/people/SamsterBirdies/sounds/621000/) by SamsterBirdies, all CC0 on Freesound.
- Aircraft: US Air Force fact sheets for the [F-22](https://www.af.mil/About-Us/Fact-Sheets/Display/Article/104506/f22/f-22-raptor/), [F-16](https://www.af.mil/About-Us/Fact-Sheets/Display/Article/104505/f-16-fighting-falcon/) and [CV-22](https://www.af.mil/About-Us/Fact-Sheets/Display/Article/104531/cv-22-osprey/); Boeing's [AH-64 specifications](https://www.boeing.com/defense/military-rotorcraft/ah-64-apache); public material from Moffett Field Museum and the 129th Rescue Wing.
- Alcatraz: National Park Service pages on the [water tower](https://www.nps.gov/places/000/alcatraz-water-tower.htm) and the [cellhouse](https://www.nps.gov/places/000/alcatraz-cellhouse.htm).
- Twin Peaks: San Francisco Recreation and Parks, [Twin Peaks Trails Improvement and Promenade](https://www.sfrecpark.org/634/Twin-Peaks-Trails-Improvement-Promenade-).
- Charleston canopy building: Heatherwick Studio's [project photographs](https://heatherwick.com/project/google-charleston-east/).
- Slime splashes: photographs of liquid splashes, used only as visual reference.
