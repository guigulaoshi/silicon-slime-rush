## Make it yours

1. [Download](https://github.com/guigulaoshi/silicon-slime-rush/archive/refs/heads/main.zip) or clone this repository and open it in Claude Code.
2. Run `/remix` and describe the places, cars and racing game you want.

下载仓库并用 Claude Code 打开，然后输入 `/remix`，告诉它你想要的地点、赛车和玩法。
